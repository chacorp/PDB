name: Stick to decisions
description: Don't keep suggesting new experiments or architecture changes. Commit to a direction and only change when scientifically proven to not work.
type: feedback
---

Don't keep proposing new experiments, loss terms, or architecture changes speculatively. Once a direction is decided, stick to it. Only pivot when there's clear scientific evidence it doesn't work.

**Why:** User is on a deadline and needs to make progress, not explore every option. Too many parallel experiments dilute focus.

**How to apply:** When asked about next steps, focus on executing the current plan rather than suggesting alternatives. Only recommend changes when the user reports concrete failure with evidence.
