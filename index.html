PDF: Point-Based Deformation Factorization
for Facial Animation Retargeting

Sihun Cha1, Author Two1, Author Three1
1Institution Name
arXiv Code

PDF retargets facial animations across diverse mesh topologies — ICT, Multiface, BIWI, CoMA and character rigs — using a unified point-based deformation representation.

Abstract

We present PDF, a point-based deformation factorization method for mesh-agnostic facial animation retargeting. Given a source facial animation sequence and a target character mesh with arbitrary topology, PDF transfers the facial expressions from the source to the target without requiring any paired training data or manual rigging. Our key idea is to factorize the per-vertex deformation into identity-independent expression codes and identity-specific coordinate weights computed from a sparse set of learned point coordinates. This factorization allows the model to generalize to unseen mesh topologies at test time. We demonstrate that PDF outperforms previous methods on diverse datasets including ICT-FaceKit, Multiface, BIWI, and CoMA.
